# Governance

## Ownership

This personal website, its writing, images, video, music configuration, design, and original implementation are controlled by the project owner.

## Decision Levels

| Area | Decision |
|---|---|
| Personal content and media | Owner only |
| Branding and license | Owner only |
| Content schema and server API | Owner approval |
| Frontend improvements | Maintainer review |
| Documentation fixes | Maintainer review |

## Review Principles

- Respect personal content and privacy.
- Preserve the visual direction.
- Keep local and production data boundaries separate.
- Require mobile evidence for visual changes.
- Do not introduce secrets into the repository.

## Final Authority

The project owner makes the final decision on all public releases and content changes.
