# Code of Conduct

## Expected Behavior

- Be respectful and constructive.
- Discuss technical problems without personal attacks.
- Respect private photos, writing, and personal information.
- Do not publish credentials or private data.
- Keep feedback relevant to the project.

## Unacceptable Behavior

- Harassment, threats, discrimination, or abuse
- Publishing private content without permission
- Submitting malicious code or unauthorized media
- Spam or deliberate disruption
- Encouraging illegal or harmful use
