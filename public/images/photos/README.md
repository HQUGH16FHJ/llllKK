# 照片文件夹

把你的照片放到这里，然后在后台管理中引用。

## 命名建议

- 使用英文或拼音命名，例如：`city-sunset.jpg`、`mountain-morning.png`
- 不要用中文文件名，避免部署后访问问题

## 引用路径

在后台管理中填写图片 URL 时：
- 本地开发：`/images/photos/你的照片.jpg`
- 部署后：`/images/photos/你的照片.jpg`

例如：
```
/images/photos/chengshi-huanghun.jpg
```

## 照片分类建议

可以按分类建子文件夹：
- `/images/photos/city/` - 城市
- `/images/photos/nature/` - 自然
- `/images/photos/portrait/` - 人像
- `/images/photos/travel/` - 旅行
