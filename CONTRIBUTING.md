# Contributing

Thank you for helping improve 刘骐硕的个人博客.

The project uses the Bantan Proprietary License. Contributions do not grant redistribution or commercial rights.

## Before Opening a Pull Request

1. Read [LICENSE](./LICENSE).
2. Search existing issues.
3. Keep one pull request focused on one problem.
4. Do not change content ownership, personal information, or media without permission.
5. Test desktop and mobile layouts.

## Pull Request Checklist

- [ ] Behavior change is described
- [ ] Affected files are listed
- [ ] Desktop verified
- [ ] Mobile verified
- [ ] No console errors
- [ ] No private information included
- [ ] Content management still works
- [ ] License and branding remain intact

## Commit Style

```text
Add article reader progress
Fix mobile photo carousel
Update local content API
```

Security issues must follow [SECURITY.md](./SECURITY.md).
