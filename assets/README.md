# 媒体替换说明

把下面文件放在当前 `assets` 目录，页面会自动加载，不需要改代码。

## 背景图

- 文件名：`background.jpg`
- 建议尺寸：横向 2400 x 1500 或更大
- 构图：主体尽量偏右，左侧会叠加文字

## 头像

- 文件名：`avatar.jpg`
- 建议尺寸：正方形 1200 x 1200
- 画面：人物或主体居中，四周留出少量空间

## 视频

- 文件名：`intro.mp4`
- 建议格式：H.264 / MP4
- 建议比例：16:9
- 建议时长：30 秒到 2 分钟

## 视频封面

- 文件名：`video-poster.jpg`
- 建议尺寸：1920 x 1080
- 作用：视频加载前显示的封面

## 照片

- 文件名：`photo-01.` 到 `photo-06.jpg`
- 建议尺寸：横向照片 2000 x 1400，竖版照片 1400 x 1800
- 建议格式：JPG、WebP 均可，保持 `jpg` 后缀最省事
- 对应顺序会直接映射到页面上的六个照片位置

## 音乐

- 文件名：`music.mp3`
- 建议格式：MP3
- 页面不会自动播放，访客需要主动点击播放按钮
- 曲名和作者在 `app.js` 顶部的 `music` 中修改

## 文章

- 文章不需要单独创建 HTML 文件
- 在 `app.js` 顶部的 `articles` 数组里修改日期、标题、摘要和正文段落
- 每个正文段落写成一组引号包围的句子，用逗号分隔

文件不存在时，页面不会显示破损图标，会继续展示内置占位画面。
