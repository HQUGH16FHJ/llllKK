# Security Policy

## Supported Versions

The current `main` branch is supported.

## Reporting a Vulnerability

Do not disclose security issues publicly. Send a private report to:

- Email: 3401049114@qq.com
- GitHub: [@HQUGH16FHJ](https://github.com/HQUGH16FHJ)

Include the affected page or endpoint, reproduction steps, browser, impact, and any safe proof of concept.

## Sensitive Information

Never submit:

- `ADMIN_TOKEN`
- Cloudflare credentials
- API keys
- Private user data
- Uploaded private photos or media
- Passwords or authentication tokens

If a secret was exposed, revoke it immediately and review deployment logs.

## Security Scope

Priority areas include:

- Admin authentication
- Content and media uploads
- Path traversal
- Unsafe file types
- Unauthorized content modification
- Sensitive data exposure
- Cross-site scripting
