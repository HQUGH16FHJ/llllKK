# 内容与媒体说明

推荐直接打开 `admin.html` 管理文章、照片和素材。本地管理可以使用
`启动管理后台.bat`，Cloudflare 部署使用 `https://你的域名/admin.html`。

下面的文件名说明用于手动替换。

## 背景图

- 文件名：`background.jpg`
- 建议尺寸：横向 2400 x 1500 或更大
- 构图：主体尽量偏右，左侧会叠加文字

## 头像

- 文件名：`avatar.jpg`
- 建议尺寸：正方形 1200 x 1200
- 画面：人物或主体居中，四周留出少量空间

## 视频

- 文件名：`intro.mp4`
- 建议格式：H.264 / MP4
- 建议比例：16:9
- 建议时长：30 秒到 2 分钟

## 视频封面

- 文件名：`video-poster.jpg`
- 建议尺寸：1920 x 1080
- 作用：视频加载前显示的封面

## 照片

- 默认位置：`assets/photos/photo-01.jpg` 等
- 建议尺寸：横向照片 2000 x 1400，竖版照片 1400 x 1800
- 建议格式：JPG、WebP 均可，保持 `jpg` 后缀最省事
- 新增、删除、上传和排序都可以在管理后台完成

## 音乐

- 文件名：`music.mp3`
- 建议格式：MP3
- 页面不会自动播放，访客需要主动点击播放按钮
- 曲名和作者在 `app.js` 顶部的 `music` 中修改

## 文章

- 文章不需要单独创建 HTML 文件
- 在管理后台新增、编辑、排序或删除文章
- 正文段落之间空一行，保存后即可在主页完整阅读

文件不存在时，页面不会显示破损图标，会继续展示内置占位画面。
