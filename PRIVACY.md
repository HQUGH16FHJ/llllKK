# Privacy

This project is a personal content website containing articles, photographs, video, music, and local content-management tools.

## Local Storage

The site may use browser storage for:

- Interface preferences
- Music state
- Media playback preferences
- Content synchronization state

## Personal Content

Articles, photographs, video, and writing remain the property of their respective owner. Do not redistribute personal media without permission.

## Media Uploads

The local server accepts image, audio, and video uploads for the content owner. Uploaded files are stored in the `assets` directory when running the local Node.js server.

## Third-Party Services

External media, fonts, or links may have their own privacy policies. The project does not control those services.
